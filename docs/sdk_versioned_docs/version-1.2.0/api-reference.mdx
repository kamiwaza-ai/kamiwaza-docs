# REST API Reference

The offline build omits the interactive REST API reference to keep SDK navigation responsive when browsing directly from disk.

Use these options instead:

- Browse the Python SDK service docs in the sidebar for offline usage.
- Open the hosted API reference when you have network access: [docs.kamiwaza.ai/sdk/api/](https://docs.kamiwaza.ai/sdk/api/)
